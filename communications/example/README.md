# EXAMPLE (the Ontology Template)

The Ontology Template is the repository template this one's tooling and method were
taken from, generalized for any BFO/CCO-aligned ontology. Its sender code in
communications ids is `EXAMPLE`, the placeholder `code` in its `config/project.yaml`,
which a project made from the template replaces with its own.

**What the template takes from this repository:** BCO's process account of 2026-10-30,
recorded in the template at `docs/template/evaluations/2026-10-30-bco-process-account.md`,
as evidence for the ontology method it proposes to write. BCO changes nothing for the
template; whether BCO adopts what the template builds is a decision of its own.
