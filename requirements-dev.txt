# Pinned dependencies for the checks in this repository.
#
# Only what the tools and tests actually import. That is verified the one
# way it can be: by installing this file into an empty environment and
# running the suite there.
#
# Pinned exactly rather than with a floor. The point of a pinned file is
# that a clean environment reproduces this one, and ">=" reproduces
# whatever was newest that day. The versions are the ones the Application
# Requirement Ontology pins, so the two repositories run the same checks
# on the same libraries.
#
# What each is for:
#
#   pytest      the suite
#   PyYAML      tools/layout.py reads the layout contract; the licensing
#               and vendoring tools read the pins and adjudications
#   rdflib      reading the ontology without a reasoner
#   pyshacl     the SHACL validation ladder
#   Markdown    tools/site/build_site.py renders the specification and the
#               review for the public site. 3.11 rather than the newest
#               3.11.x: the newest was days old when this was pinned.
#
# ARO also pins jsonschema and owlrl. Nothing ported here imports either,
# and ARO's own rule is to take out a pin nothing exercises, so they are
# not carried over. Add them back in the commit that adds the check that
# needs them.
