# P2 LinkML trial: the full resolved environment, pinned exactly.
#
# TRIAL ONLY. Not requirements-dev.txt, and nothing in the normal suite
# installs or imports it. ADR-003 D9 adopts LinkML only on a P2 "go";
# this file exists so that the trial in docs/trials/2026-10-p2-linkml.md
# can be re-run byte for byte.
#
# Why every transitive package is listed, not only linkml:
#
#   `pip install linkml==1.11.1` alone, on 2026-10-23, resolved 88
#   packages, 20 of them uploaded to PyPI less than two weeks earlier --
#   including linkml-runtime 1.12.1 (2026-10-13), a newer minor than the
#   linkml it serves. Pinning only the top-level package reproduces
#   whatever was newest on the day (docs/process/PROCESS.md section 8).
#   Each of those 20 is replaced here by the newest final release uploaded
#   before 2026-10-09; linkml-runtime is held at 1.11.1, the release cut
#   with linkml 1.11.1 on 2026-05-20.
#
# Why linkml 1.11.1 and not 1.12.0: 1.12.0 was uploaded 2026-10-08, one
# day inside the two-week rule, six hours after its last release
# candidate, and was followed by 1.12.1 five days later. 1.11.1 has been
# out five months.
#
# Holding linkml-runtime at 1.11.1 changes the graph: it pulls pystow,
# tqdm and backports.zstd, which 1.12.1 did not. Those three are pinned
# too (pystow and backports.zstd likewise held below 2026-10-09), so the
# file is the whole installed set: 91 packages, checked by installing it
# into an empty venv and comparing `pip freeze` with this list.
#
# rdflib, pyshacl and PyYAML are the repository's own pins
# (requirements-dev.txt); the resolver accepted them without conflict.
#
# Install:   py -3.12 -m venv .venv-linkml
#            .venv-linkml/Scripts/python -m pip install -r trials/p2-linkml/requirements-linkml-trial.txt
